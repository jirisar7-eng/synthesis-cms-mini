# SDK Layer (sdk/)

## Purpose
The `sdk/` directory establishes the boundary for developer Software Development Kits in Synthesis CMS mini.

## Scope & Boundaries
- **Belongs here:** Future SDK packages providing typed clients, module development utilities, and integration helpers.
- **Explicitly does NOT belong yet:** No SDK implementations, npm packages, or runtime utilities are created in Step 7.
- **Future Roadmap:** Public SDK packages will be developed in alignment with module runtime and API contracts.
- **Status:** Structural ownership boundary established for Step 7.

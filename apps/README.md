# Applications Layer (apps/)

## Purpose
The `apps/` directory defines the boundary for future client-facing and administrative application entry-points in Synthesis CMS mini.

## Scope & Boundaries
- **Belongs here:** Future web client applications, admin UI dashboards, and headless consumer frontends.
- **Explicitly does NOT belong yet:** No runtime application code, UI frameworks (React, Next.js, Vite), bundling configurations, or server implementations are created in Step 7.
- **Future Roadmap:** Runtime setup and framework baseline will be evaluated and introduced in Step 8 (Toolchain Baseline) and subsequent application steps.
- **Status:** Structural ownership boundary established for Step 7.

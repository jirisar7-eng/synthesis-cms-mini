# Documentation Layer (docs/)

## Purpose
The `docs/` directory defines the boundary for technical, architectural, and operational documentation.

## Scope & Boundaries
- **Belongs here:** Architectural decision records, system diagrams, developer onboarding guides, and operational references.
- **Authoritative Evidence Distinction:** This directory does not replace or duplicate immutable governance records, capsules, or attestations, which reside exclusively in `.synthesis/`.
- **Explicitly does NOT belong:** No transient build artifacts or unapproved proposals.
- **Status:** Structural ownership boundary established for Step 7.

# Scripts & Tooling Layer (scripts/)

## Purpose
The `scripts/` directory documents repository tooling and automation in Synthesis CMS mini.

## Scope & Boundaries
- **Belongs here:** Repository automation, maintenance scripts, and development tooling.
- **Authoritative Governance Authority:** `scripts/governance/` contains authoritative governance validation tooling (capsule seal verification, attestation chain validation, diff firewall, genesis verification). Its structure and authority are fully preserved and must never be duplicated.
- **Explicitly does NOT belong:** No runtime application code.
- **Status:** Structural documentation established for Step 7.

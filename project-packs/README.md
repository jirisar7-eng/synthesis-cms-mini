# Project Packs Layer (project-packs/)

## Purpose
The `project-packs/` directory defines the composition boundary for project distributions and packages.

## Scope & Boundaries
- **Belongs here:** Future pre-packaged distributions, default configurations, themes, and feature bundles that compose modular features without forking Core.
- **Explicitly does NOT belong yet:** No project-specific configurations, packs, or theme assets are created in Step 7.
- **Future Roadmap:** Project pack composition contracts and lifecycle schemas will be specified in later roadmap phases.
- **Status:** Structural ownership boundary established for Step 7.
